# Code of Conduct

## Our pledge

We want a welcoming project for everyone, regardless of experience, background, identity, or ability. We pledge to make participation harassment-free.

## Expected behavior

- Be respectful and assume good intent.
- Give technical feedback about the work, not the person.
- Accept correction and correct mistakes openly.
- Respect privacy. Do not publish another person's logs, tokens, topics, or private data.
- Keep discussions on topic and avoid personal attacks.

## Unacceptable behavior

- Harassment, threats, discriminatory language, or unwanted sexual attention.
- Publishing private information without permission.
- Deliberate intimidation, stalking, or sustained disruption.
- Bad-faith security reports, doxxing, or sharing exploit details before a fix is available.

## Scope

This code applies in the repository, issues, pull requests, discussions, and any project space. It also applies when you represent the project in public.

## Reporting

Report a concern privately to the maintainer through GitHub. For a security vulnerability, use GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md). Do not use a public issue for a conduct report or a vulnerability.

The maintainer will review the report, keep it confidential where possible, and decide on a response. Responses may include a warning, removal of content, a temporary ban, or a permanent ban.
